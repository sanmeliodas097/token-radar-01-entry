Every protocol that records no token yet, ranked by what its launch would be worth — and how to farm it. Snapshot . Implied values are this entry's own claim, not a prediction that a token will launch.

How the value is worked out

Multiple per category = median mcap / TVL of the snapshot's own token-bearing protocols in that category (global median fallback). Growth = 7-day TVL change clamped to −60…+120%. Maturity rises with how long a protocol has run with no token. No protocol name is ever special-cased — the same formula scores every row.
